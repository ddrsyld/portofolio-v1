# Portfolio - Dedy Risyaldi

Personal portfolio website built with React, Vite, and Tailwind CSS.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/ddrsyld/portofolio-v1.git
cd portofolio-v1
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
