# Dedy Risyaldi - Personal Portfolio

A modern, high-performance developer portfolio built with **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Tech Stack

- **Framework / UI:** React 19, Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite
- **Typography:** Plus Jakarta Sans & JetBrains Mono

## 📦 Project Structure

`
MyPortofolio/
├── public/                # Static assets (Favicon, PDF documents, avatar)
├── src/
│   ├── components/        # UI Section Components (Hero, About, Experience, Skills, etc.)
│   ├── data/              # Portfolio content data (portfolioData.js)
│   ├── App.jsx            # Main App layout & Theme Switcher
│   ├── main.jsx           # React root entry
│   └── index.css          # Tailwind CSS and global style utilities
├── index.html             # HTML entry template
├── tailwind.config.js     # Tailwind design system configuration
└── vite.config.js         # Vite bundler configuration
`

## 🛠️ Getting Started

### 1. Clone Repository
`ash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

### 4. Build for Production
`ash
npm run build
`
