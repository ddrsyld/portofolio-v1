# Dedy Risyaldi — Personal Portfolio

Modern, responsive, and minimalist developer portfolio built with **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## ⚡ Tech Stack

- **Frontend Framework:** React 19
- **Styling & Design System:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Typography:** Plus Jakarta Sans & JetBrains Mono
- **Build Tool:** Vite

---

## ✨ Features

- **🌓 Dark / Light Mode Toggle:** Seamless theme switching with local storage persistence and system preference detection.
- **📱 Fully Responsive Design:** Fluid layouts optimized for mobile, tablet, and widescreen desktop displays.
- **✨ Smooth Motion & Micro-interactions:** Engaging scroll animations, card elevations, and hover states powered by Framer Motion.
- **🎯 Dynamic Skills & Proficiency Filter:** Interactive category filtering for Desktop (.NET/Java), AI & ML, Web & Backend, and Cloud stacks.
- **💼 Interactive Honors & Certifications:** Direct integration and verification links to professional profiles.

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/ddrsyld/portofolio-v1.git
cd portofolio-v1
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
